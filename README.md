# Reading Tracker (Stand: erste Version)
Setup: `npm install`, `.env.example` nach `.env.local` kopieren und Werte eintragen, `supabase/migrations/001_schema_rls.sql` im Supabase-SQL-Editor ausführen, `npm run dev`.
Deployment: Secrets `VITE_SUPABASE_URL` und `VITE_SUPABASE_PUBLISHABLE_KEY` in GitHub anlegen, Pages-Quelle „GitHub Actions“ wählen. Ausführliche Anleitung folgt.
